A [make.fun](https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72) bounty entry: one word that describes home Wi-Fi, aiming to be both the funniest and the most accurate.

## The word

**Moody** — home Wi-Fi that works beautifully one minute and sulks in the corner the next, for no reason anyone can explain.

## Why this word

Most Wi-Fi complaints are about speed — slow, laggy, buffering. This entry
takes a different angle: the router as a moody housemate. Everyone has lived
it: full bars during a casual scroll, dead air the second a video call
starts. One word, no explanation needed, and instantly recognisable as true.

## How it works

`main.py` (Python 3.13, standard library only) writes exactly one word to `/output/entry.txt`. The output is deterministic: the same bytes on every run.

```bash
python3 main.py
cat /output/entry.txt
```
